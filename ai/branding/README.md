# Кастомный брендинг

Бренд системы — **Corporate** (example.com). Готовые ассеты уже лежат в образе,
в `client/public/assets/`, и собираются вместе с фронтендом — отдельно
подкладывать ничего не нужно.

Эта папка нужна только для локального docker-compose: она монтируется в
контейнер `api` как `/app/client/public/assets` (см. `docker-compose.override.yml`)
и подменяет ассеты, не пересобирая образ. Пока она пуста, монтирование
перекрывает штатные файлы — либо не монтируйте её, либо кладите сюда
полный набор.

Имена файлов менять нельзя — приложение ссылается на них по этим именам.

## Что можно заменить

| Файл                          | Назначение                                     |
|-------------------------------|------------------------------------------------|
| `logo.svg`                    | Логотип (экран входа и регистрации)            |
| `corporate-mark.svg`             | Знак без текста: иконка эндпоинта в чате       |
| `favicon-16x16.png`           | Favicon 16x16                                  |
| `favicon-32x32.png`           | Favicon 32x32                                  |
| `apple-touch-icon-180x180.png`| Иконка для iOS (добавление на главный экран)   |
| `icon-192x192.png`            | Иконка PWA / манифест                          |
| `maskable-icon.png`           | Адаптивная иконка PWA (maskable)               |

## Фирменные цвета

| Роль            | Значение  |
|-----------------|-----------|
| Фон знака       | `#0B1B33` |
| Градиент, начало| `#34D3B5` |
| Градиент, конец | `#3B82F6` |

## Название

`APP_TITLE` и `CUSTOM_FOOTER` в `deploy/10-config.yaml` (для локального
запуска — в `.env`). Эта папка их не затрагивает.

Имя эндпоинта `Corporate AI` в `librechat.yaml` — не бренд, а внутренний
идентификатор: оно записано в каждом существующем разговоре и совпадает с
`endpointName` в `packages/api/src/corporate/provider.ts`, по которому снимается стоимость в рублях.
Сотруднику видны `modelDisplayLabel` и `iconURL`, их и меняйте.

## Как применить

1. Положить файлы с указанными именами в эту папку.
2. Перезапустить контейнер: `docker compose up -d --force-recreate api`.
